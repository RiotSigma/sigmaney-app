# Σ₽ Sigmaney — Автономный мобильный трекер личных финансов



**Sigmaney** — мобильное приложение для учёта доходов, расходов и автоматического разбора кассовых чеков. Проект построен по принципу *local-first*: все финансовые данные хранятся изолированно в локальной памяти устройства без привязки к сторонним облачным базам данных, а сборка нативного Android `.apk` автоматизирована через Capacitor и GitHub Actions.



---



## Ключевые возможности



- **Автоматический мульти-раздел чеков (без `.txt` и `.json`)** — позиции одного чека (например, продукты, канцелярия и аптека) автоматически распределяются по соответствующим категориям. Для QR-чеков в настройках доступен выбор режима: запрос состава по API (`proverkacheka.com`), встроенный офлайн-редактор или гибридный режим.

- **Пакетная загрузка чеков из почты за период** — интеграция через бесплатный мост **Google Apps Script** позволяет загружать электронные чеки ОФД за выбранный интервал (*сегодня*, *неделя*, *месяц*, *всё время*) из Gmail, а также из Mail.ru и Яндекс.Почты (через автопересылку).

- **Сквозная дедупликация (Почта ↔ СМС ↔ QR)** — двухуровневая проверка по фискальным реквизитам (`ФН`, `ФД`, `ФП`) и по связке *дата + сумма + магазин* исключает повторный учёт одного и того же чека из разных источников.

- **3-уровневая БД категорий для оптимизации памяти** — категории распределяются по трём изолированным хранилищам в зависимости от частоты использования:

  1. **БД-1 (Часто используемые, 3+ покупок)** — хранятся в быстром горячем кэше;

  2. **БД-2 (Нечасто используемые, 2 покупки)** — промежуточный уровень;

  3. **БД-3 (Единоразовые, 1 покупка)** — подгружаются лениво по требованию.

- **Мультиаккаунтность и безопасность** — поддержка нескольких независимых профилей на одном смартфоне, хэширование паролей (`SHA-256`) и локальное восстановление доступа по резервному коду (`SGM-XXXX-XXXX`).

- **Мобильный интерфейс** — адаптивная вёрстка под управление одной рукой, светлая и тёмная темы, встроенный QR-сканер через камеру устройства.



---



## Стек и архитектура



- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (CSS Variables, адаптивная мобильная сетка)

- **Хранилище:** Изолированный `localStorage` (3-уровневая схема категорий + кэш фискальных отпечатков)

- **Мобильная обёртка:** Capacitor (Android WebView, нативные разрешения камеры и сети)

- **Почтовый мост:** Google Apps Script (JSON Web App Endpoint)

- **CI/CD:** GitHub Actions (автоматическая сборка `app-debug.apk` при каждом обновлении ветки `main`)



---



## Сборка Android APK



1. Откройте вкладку **Actions** в репозитории GitHub.

2. Выберите рабочий процесс **Build Sigmaney Android APK** и нажмите **Run workflow** (или просто обновите `www/index.html` в ветке `main`).

3. После завершения сборки скачайте артефакт **Sigmaney-APK** и установите `app-debug.apk` на Android-устройство.
