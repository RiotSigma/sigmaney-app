# Sigmaney — Android APK (Capacitor)

## Как собрать .apk на GitHub в один клик
1. Создайте новый репозиторий на GitHub (например, `sigmaney-app`).
2. Распакуйте этот архив и загрузите все файлы (включая скрытую папку `.github/workflows/build-apk.yml`) в корень репозитория.
3. Откройте вкладку **Actions** в репозитории → выберите **Build Sigmaney Android APK** → нажмите **Run workflow** (или дождитесь автосборки после push).
4. Через 2–3 минуты откройте завершённый запуск и скачайте артефакт **Sigmaney-APK** (`app-debug.apk`).
5. Перенесите `.apk` на телефон и установите (разрешите установку из неизвестных источников).

## Как обновить интерфейс
Замените файл `www/index.html` новой версией и сделайте commit — GitHub Actions автоматически пересоберёт свежий `.apk`.
